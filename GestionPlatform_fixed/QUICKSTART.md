# 🚀 Guide de Démarrage Rapide

## Installation en 3 étapes

### Étape 1 : Vérifier les prérequis

Assurez-vous d'avoir installé :
- ☑️ Java JDK 17 ou supérieur
- ☑️ Maven 3.6 ou supérieur

Pour vérifier :
```bash
java -version
mvn -version
```

### Étape 2 : Lancer l'application

#### Sur Windows :
Double-cliquez sur `run.bat` ou exécutez dans un terminal :
```bash
run.bat
```

#### Sur Linux/Mac :
Exécutez dans un terminal :
```bash
./run.sh
```

#### Manuellement avec Maven :
```bash
mvn clean compile
mvn javafx:run
```

### Étape 3 : Explorer l'application

L'application se lance automatiquement avec :
- ✅ Interface moderne avec sidebar
- ✅ 5 modules de gestion disponibles
- ✅ Données de démonstration pré-chargées

## 🎯 Modules Disponibles

1. **GESTION UTILISATEURS** - Gérer les utilisateurs
2. **GESTION ÉVÉNEMENTS** - Organiser des événements
3. **GESTION COACHING** - Suivre les sessions
4. **GESTION BLOG** - Gérer les articles
5. **GESTION PRODUITS/COMMANDES** - Gérer le catalogue

## 🎨 Interface

- **Couleur principale** : #17BB9C (Vert)
- **Sidebar** : #1a2332 (Bleu nuit)
- **Actions** : Ajouter, Modifier, Supprimer, Exporter
